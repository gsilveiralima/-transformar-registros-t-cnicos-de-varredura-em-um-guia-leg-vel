# -transformar-registros-t-cnicos-de-varredura-em-um-guia-leg-vel
O código apresentado descreve um script em Python desenvolvido para criar um relatório de segurança em formato PDF sobre atividades suspeitas no Gmail. Através da biblioteca ReportLab, o programa organiza dados sobre e-mails que apresentam sinais de phishing, engenharia social ou tentativas de acesso não autorizado.
